## Main Navigation

### Top Navigation Bar

<Tabs>
  <Tab title="Portfolio Overview">
    **Your Trading Portfolio**
    
    Quick access to portfolio-wide metrics:
    
    ```typescript
    interface PortfolioMetrics {
      totalValue: number;        // Current portfolio value in SOL
      dailyPnL: number;         // Today's profit/loss
      totalReturn: number;      // All-time return percentage
      activeAgents: number;     // Currently running agents
      successRate: number;     // Overall success rate
      riskScore: number;        // Current risk level (0-100)
    }
    ```
    
    **Key Features:**
    - Real-time value updates
    - Performance comparison charts
    - Risk level indicators
    - Quick action buttons
  </Tab>
  
  <Tab title="Alerts & Notifications">
    **Stay Informed**
    
    The notification center shows:
    
    - **Performance Alerts**: Significant gains or losses
    - **Risk Warnings**: When agents exceed risk thresholds
    - **System Updates**: Platform news and updates
    - **Trade Confirmations**: Successful trade executions
    
    <AccordionGroup>
      <Accordion title="Alert Types">
        - 🔴 **Critical**: Immediate action required
        - 🟡 **Warning**: Monitor closely
        - 🟢 **Success**: Positive performance
        - 🔵 **Info**: General updates
      </Accordion>
      
      <Accordion title="Notification Settings">
        Customize alerts for:
        - Performance thresholds
        - Risk levels
        - Trade confirmations
        - System maintenance
      </Accordion>
    </AccordionGroup>
  </Tab>
  
  <Tab title="Quick Actions">
    **Fast Controls**
    
    Instant access to common actions:
    
    - **Emergency Stop All**: Halt all agent trading
    - **Deploy New Agent**: Quick agent deployment
    - **Fund Agents**: Add capital to agent wallets
    - **Generate Report**: Create performance summary
    
    ```json
    {
      "emergencyStop": {
        "confirmation": "required",
        "affects": "all_active_agents",
        "reversible": true
      }
    }
    ```
  </Tab>
</Tabs>

## Agent Status Monitor

### Real-Time Agent Grid

<img src="/images/agent-grid.png" alt="Agent Status Grid" />

Each agent card displays:

<AccordionGroup>
  <Accordion title="Agent Identity">
    **Basic Information**
    
    - **Agent Name**: Custom or auto-generated name
    - **Agent Type**: Sniper, Arbitrage, LP Optimizer, etc.
    - **Status Indicator**: Active, Idle, Error, Learning
    - **Uptime**: How long the agent has been running
    
    ```typescript
    interface AgentIdentity {
      id: string;
      name: string;
      type: AgentType;
      status: 'active' | 'idle' | 'error' | 'learning';
      uptime: number;        // Hours
      lastSeen: Date;
    }
    ```
  </Accordion>
  
  <Accordion title="Performance Metrics">
    **Key Performance Indicators**
    
    - **Success Rate**: Percentage of profitable trades
    - **Total PnL**: Cumulative profit/loss
    - **ROI**: Return on investment percentage
    - **Trades Today**: Number of trades executed
    - **Average Trade Time**: Typical holding period
    
    Color-coded performance indicators:
    - 🟢 **Green**: Outperforming expectations
    - 🟡 **Yellow**: Meeting expectations
    - 🔴 **Red**: Underperforming
  </Accordion>
  
  <Accordion title="Current Activity">
    **What's Happening Now**
    
    - **Active Positions**: Currently held tokens
    - **Pending Orders**: Trades waiting to execute
    - **Last Action**: Most recent agent activity
    - **Next Action**: Predicted upcoming activity
    
    Real-time activity feed shows:
    ```json
    {
      "timestamp": "2024-12-24T10:30:15Z",
      "action": "BUY",
      "token": "$BONK",
      "amount": "1.2 SOL",
      "confidence": 0.87,
      "reasoning": "Strong social sentiment + technical breakout"
    }
    ```
  </Accordion>
</AccordionGroup>

## Trading Terminal

### Live Trading Interface

<img src="/images/trading-terminal.png" alt="Trading Terminal" />

<Tabs>
  <Tab title="Active Positions">
    **Current Holdings Management**
    
    Monitor and manage all open positions:
    
    **Position Cards Show:**
    - Token name and current price
    - Entry price and current PnL
    - Position size and allocation
    - Time held and target exit
    - Risk level and stop loss
    
    **Quick Actions:**
    - Close position immediately
    - Adjust stop loss/take profit
    - Increase/decrease position size
    - Set time-based exit
    
    ```typescript
    interface Position {
      token: string;
      entryPrice: number;
      currentPrice: number;
      amount: number;
      pnl: number;
      pnlPercent: number;
      timeHeld: number;        // minutes
      stopLoss?: number;
      takeProfit?: number;
    }
    ```
  </Tab>
  
  <Tab title="Execution Queue">
    **Pending Operations**
    
    View and manage pending trades:
    
    **Queue Information:**
    - Trade type (Buy/Sell/Arbitrage)
    - Token and amount
    - Priority level
    - Estimated execution time
    - Current status
    
    **Queue Management:**
    - Cancel pending orders
    - Adjust priority levels
    - Modify order parameters
    - View execution history
    
    **Status Indicators:**
    - 🟡 **Pending**: Waiting for execution
    - 🔵 **Processing**: Currently executing
    - 🟢 **Completed**: Successfully executed
    - 🔴 **Failed**: Execution failed
  </Tab>
  
  <Tab title="Market Data">
    **Real-Time Market Information**
    
    **Price Charts:**
    - Real-time price feeds
    - Multiple timeframes (1m, 5m, 15m, 1h, 4h, 1d)
    - Technical indicators
    - Volume analysis
    
    **Market Metrics:**
    - Current prices across DEXs
    - Liquidity depth
    - Trading volume
    - Price volatility
    - Social sentiment
    
    **Opportunity Scanner:**
    - New token launches
    - Arbitrage opportunities
    - Volume spikes
    - Price breakouts
  </Tab>
</Tabs>
