## Arbitrage Engines

<img src="/images/arbitrage-agent.png" alt="Arbitrage Engine finding cross-DEX opportunities" />

**The Profit Miners**

Arbitrage engines identify and exploit price differences across DEXs for risk-free profits.

### Arbitrage Types

<Tabs>
  <Tab title="Simple Arbitrage">
    **Direct Price Differences**
    
    Buy low on one DEX, sell high on another:
    
    ```python
    def find_arbitrage_opportunities():
        opportunities = []
        
        for token in monitored_tokens:
            prices = {
                'Uniswap': get_price(token, 'Uniswap'),
                'Curve': get_price(token, 'Curve'),
                'SushiSwap': get_price(token, 'SushiSwap')
            }
            
            max_price = max(prices.values())
            min_price = min(prices.values())
            spread = (max_price - min_price) / min_price
            
            if spread > 0.005:  # 0.5% minimum
                opportunities.append({
                    'token': token,
                    'spread': spread,
                    'buy_dex': min(prices, key=prices.get),
                    'sell_dex': max(prices, key=prices.get),
                    'profit_estimate': calculate_profit(spread, token)
                })
        
        return opportunities
    ```
  </Tab>
  
  <Tab title="Triangular Arbitrage">
    **Multi-Hop Profit Cycles**
    
    Exploit price differences across trading pairs:
    
    - ETH → TOKEN → USDC → ETH across multiple chains
    - Identify profitable cycles
    - Execute all trades atomically
    - Account for fees and slippage
  </Tab>
  
  <Tab title="Flash Loan Arbitrage">
    **Capital-Free Arbitrage**
    
    Use flash loans to execute large arbitrage trades without capital:
    
    - Borrow large amounts instantly
    - Execute arbitrage trade
    - Repay loan with interest
    - Keep the profit
