# Frequently Asked Questions

Common questions and answers about using c0gni autonomous trading agents.

## Getting Started

<AccordionGroup>
  <Accordion title="What is c0gni?">
    c0gni is an **Agent Operating System** for autonomous trading on Solana. Unlike traditional bots that follow pre-programmed rules, c0gni agents are autonomous entities that learn, adapt, and make decisions based on real-time market conditions and their own trading experience.

    **Key Differences from Bots:**
    - **Learning**: Agents remember and learn from every trade
    - **Adaptation**: Strategies evolve based on performance
    - **Speed**: <400ms execution from opportunity detection
    - **Coordination**: Multiple agents can work together as swarms
  </Accordion>

  <Accordion title="How much money do I need to start?">
    **Minimum Requirements:**
    - **Basic Agent**: 0.5 SOL ($20-50 depending on SOL price)
    - **Recommended Starting Amount**: 2-5 SOL for optimal performance
    - **Advanced Swarms**: 10+ SOL for full multi-agent capabilities

    **What's Included:**
    - Agent deployment costs (~0.01 SOL)
    - Initial trading capital
    - Transaction fees and priority fees
    - Ongoing operational costs

    **Pro Tip**: Start small to learn how agents work, then scale up as you gain confidence.
  </Accordion>

  <Accordion title="Are my funds safe?">
    **Security Measures:**
    - **Non-Custodial**: You maintain control of your funds
    - **Smart Contract Audited**: All core contracts are formally audited
    - **Risk Controls**: Built-in stop losses and position limits
    - **Emergency Stops**: Instantly halt all agent activity
    - **Transparent**: All transactions visible on Solana blockchain

    **Risk Considerations:**
    - Trading inherently involves risk of loss
    - Agents can make unprofitable trades
    - Smart contract risk (though minimized through audits)
    - Market volatility can cause rapid losses

    **Remember**: Only invest what you can afford to lose.
  </Accordion>

  <Accordion title="How do agents learn and adapt?">
    **Learning Mechanisms:**

    1. **Trade Memory**: Every trade is stored on-chain with outcomes
    2. **Pattern Recognition**: Successful strategies are reinforced
    3. **Failure Analysis**: Losses trigger strategy adjustments  
    4. **Market Adaptation**: Performance tracking across different market conditions
    5. **Cross-Agent Learning**: Agents can learn from swarm collective memory

    **Example Learning Process:**
    ```
    Agent notices it performs better during:
    - High volume periods (learns to be more active)
    - Certain times of day (adjusts scheduling)
    - Specific token categories (refines preferences)
    - Bull vs bear markets (adapts risk tolerance)
    ```

    **Timeline**: Most agents show meaningful adaptation within 2-4 weeks of operation.
  </Accordion>
</AccordionGroup>

    1. **Detection** (<5 seconds)

       - Identify trading opportunities

    2. **Analysis** (~30 seconds)

  <Accordion title="What's the difference between agents and swarms?">
    **Individual Agents:**
    - Single specialized function
    - Independent decision making
    - Simpler to manage
    - Lower capital requirements
    - Good for specific strategies

    **Agent Swarms:**
    - Multiple coordinated agents
    - Collective intelligence
    - Enhanced performance through specialization
    - Higher capital requirements
    - Complex multi-strategy approach

    **Swarm Example:**
    ```
    Scout Agent → Finds opportunities
    Analyzer Agent → Assesses risk
    Trader Agent → Executes trades  
    Hedger Agent → Manages risk
    Monitor Agent → Tracks performance
    ```

    **Performance Improvement**: Swarms typically show 23% higher success rates than individual agents.

  <Accordion title="How does MEV protection work?">
    **MEV (Maximum Extractable Value) Threats:**
    - Front-running: Bots copy successful trades
    - Sandwich attacks: Price manipulation around trades
    - Arbitrage extraction: Value extracted from price differences

    **c0gni's Protection (via Jito):**

    1. **Private Mempool**
       - Transactions hidden until execution
       - Prevents front-running bots from seeing trades

    2. **Bundle Execution**
       - Multiple transactions executed atomically
       - Reduces MEV extraction opportunities

    3. **Priority Fees**
       - Agents bid for transaction priority
       - Ensures fast execution before MEV bots

    **Effectiveness**: ~90% reduction in MEV losses compared to public mempool trading.
  </Accordion>

## Troubleshooting

<AccordionGroup>
  <Accordion title="My agent isn't trading. What's wrong?">
    **Common Causes & Solutions:**

    **1. Insufficient Capital**
    - Check agent wallet balance
    - Ensure enough SOL for trades + fees
    - Add funds if needed

    **2. Conservative Settings**
    - Risk parameters too restrictive
    - Opportunity thresholds too high
    - Market conditions don't match criteria

    **3. Market Conditions**
    - Low volatility periods
    - Insufficient opportunities
    - High competition for trades

    **4. Technical Issues**
    - RPC connection problems
    - Network congestion
    - Agent program errors

    **Diagnostic Steps:**
    1. Check agent status indicator
    2. Review recent activity logs
    3. Verify wallet funding
    4. Check alert notifications
    5. Contact support if issues persist
  </Accordion>

  <Accordion title="How do I stop my agent?">
    **Immediate Stop Options:**

    **1. Emergency Stop**
    - Red "Emergency Stop" button on dashboard
    - Halts all trading immediately
    - Closes open positions at market price
    - Reversible (can restart later)

    **2. Pause Agent**
    - Pause button on agent card
    - Stops new trades but keeps positions
    - Monitoring continues
    - Easy to resume

    **3. Deactivate Agent**
    - Settings → Deactivate
    - Closes positions and stops agent
    - Withdraws remaining funds
    - Requires redeployment to restart

    **Note**: Emergency stops execute within 5-10 seconds.
  </Accordion>
